# 🗺️ Greater Hyderabad Spatial Analysis (GIS)

![Python](https://img.shields.io/badge/Python-3.11-blue.svg)
![Jupyter](https://img.shields.io/badge/Jupyter-Notebook-F37626.svg?logo=jupyter)
![QGIS](https://img.shields.io/badge/QGIS-Geospatial-589632.svg?logo=qgis)

A geospatial analysis project focused on mapping and evaluating the Area of Interest (AOI) within Greater Hyderabad. This project combines automated Python scripting with robust QGIS visualizations to process shapefiles and extract spatial intelligence.

## ✨ Features
* **Automated Spatial Data Processing:** Python-based Jupyter notebooks (`GIS_Script.ipynb`) for cleaning, projecting, and analyzing geographical datasets.
* **Shapefile Integration:** Complete geospatial data package containing `.shp`, `.shx`, `.dbf`, and `.prj` files for the Greater Hyderabad AOI.
* **QGIS Workspace:** A pre-configured QGIS project (`Hyderabad.qgz`) for immediate visual exploration of the geographic overlays.

## 🛠️ Tech Stack
* **Languages & Environments:** Python, Jupyter Notebook
* **GIS Software:** QGIS
* **Data Formats:** ESRI Shapefiles (.shp), Spatial Databases (.dbf)

## 🚀 Getting Started
1. **Clone the repository:** `git clone <repo-url>`
2. **Explore the Data:** Open `Hyderabad.qgz` in QGIS (v3.x+) to view the pre-styled map layers.
3. **Run the Notebook:** Launch Jupyter Notebook and open `GIS_Script.ipynb` to view the programmatic spatial analysis and data manipulation steps.
